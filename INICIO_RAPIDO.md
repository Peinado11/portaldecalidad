# ⚡ INICIO RÁPIDO (5 Minutos)

## 🚀 Probar en tu computadora

### 1️⃣ Instalar Node.js
- Ve a: https://nodejs.org
- Descarga y instala la versión LTS

### 2️⃣ Abrir terminal en la carpeta del proyecto
```bash
cd portaldecalidad
```

### 3️⃣ Instalar dependencias
```bash
npm install
```

### 4️⃣ Iniciar aplicación
```bash
npm start
```

### 5️⃣ Abrir navegador
```
http://localhost:3000
```

### 6️⃣ Login
- Usuario: `admin`
- Contraseña: `admin1`

---

## 🌐 Ponerlo en Internet (Railway - GRATIS)

### 1️⃣ Subir a GitHub
```bash
git add .
git commit -m "Mi plataforma de onboarding"
git push
```

### 2️⃣ Ir a Railway
- https://railway.app
- Iniciar sesión con GitHub

### 3️⃣ Deploy
- "New Project" → "Deploy from GitHub"
- Seleccionar repositorio
- Esperar 3 minutos

### 4️⃣ Generar URL
- Settings → Networking → Generate Domain

### 5️⃣ ¡Listo!
Abre la URL y usa: `admin` / `admin1`
